# Fonte

Fraunces og DM Sans, hentet fra Google Fonts 5. oktober 2026 (latin, latin-ext og vietnamesisk). Begge er under SIL Open Font License 1.1, se OFL-Fraunces.txt og OFL-DMSans.txt.

`fonts.css` er Google Fonts' egen CSS med lokale filnavne i stedet for links til fonts.gstatic.com.

Ingen af de to fonte har arabiske, persiske, kyrilliske eller etiopiske tegn. Det skal løses, før siden oversættes (arkitekturgennemgangen, punkt 5).
